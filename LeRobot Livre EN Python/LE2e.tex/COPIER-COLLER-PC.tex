{ % start of the minipage
\begin{minipage}[t]{13.2cm}
\vspace{2ex}
\begin{enumerate}
\item Click with the mouse at the beginning of the text to be copied to place
the blinking edit cursor there.
\item Hold the shift key \toucheMaj\ down and click at the end
of the text to be copied, so that the text to be copied
appears {\em highlighted} (you can also drag the mouse
from the beginning to the end of the text while holding its button down).
\item Hold the control key \toucheCtrl\ down while pressing
the key \toucheL{C} to {\em copy} the selected text.
\item Click with the mouse at the place where the text is to be copied.
\item Hold the control key \toucheCtrl\ down while pressing
the key \toucheL{V} to {\em paste} the copied text.
\end{enumerate}
The copying operation (\toucheCtrl\toucheL{V}) at any place in the
program can be repeated as many
times as necessary. In case of error, \toucheCtrl\toucheL{Z} undoes the
last change.
\vspace{2ex}
\end{minipage} 
} % end of the minipage
