En réponse à nos questions, notre \robot\ peut indiquer dans quelle direction il est orienté.
N'étant pas doué de la parole, ses réponses sont {\em booléennes} \index{Booléen} c'est-à-dire 
{\idt true} (prononcer ``trou'', {\em vrai} \index{Vrai} en anglais) ou {\idt false} (prononcer ``faulse'', 
{\em faux} \index{Faux} en anglais). On peut imaginer qu'il donne ses réponses à l'aide d'un voyant lumineux
qu'il allume pour répondre  {\idt true} (vrai) et qu'il laisse éteint pour répondre {\idt false}
(faux).

En \ocaml, l'instruction de test ``if'' permet de n'exécuter une séquence d'instructions que
si une certaine {\em expression booléenne} \index{Expression booléenne}est vraie ({\idt true}).  Pour commencer nous allons
utiliser des expressions booléennes simples, à savoir les commandes de test d'orientation du \robot\
({\idt tn ()}, {\idt tne ()}, {\idt te ()}, {\idt tse ()}, {\idt ts ()}, {\idt tsw ()}, {\idt tw ()}, {\idt tnw ()}). Dans sa
forme la plus simple, l'instruction de test ``if'' s'écrit comme suit~:

\index{Test}
\begin{center}
\begin{tabular}{@{}|p{12.6cm}|@{}} \hline
{\em Test ``if'' à une seule alternative~:}\\ \hline \hline
\begin{minipage}[t]{12.6cm}
{\medskip
\mbox{\blc\ \ \ {\mcl if}\hspace{0.3em}\blanc\hspace{0.3em}{\small\rm expression booléenne}%
\footnote{\ A résultat {\idt true} (vrai) ou {\idt false} (faux).} \hspace{0.3em}\blanc\hspace{0.3em}{\mcl then}\hspace{0.3em}\blanc\hspace{0.3em}{\mcl begin}}\par 
\mbox{\blc\ \ \ \ \ \small\rm  \ldots\ Instructions (séparées par des `$;$') exécutées seulement si}\par 
\mbox{\blc\ \ \ \ \ \small\rm  l'expression booléenne vaut {\idt true} \ldots}\par 
\mbox{\blc\ \ \ {\mcl end}}\par 
\medskip}
\end{minipage}\\ \hline 
\end{tabular}
\end{center}

On peut traduire en français par {\idt si} \ldots\ {\idt alors} {\idt début}  \ldots\ {\idt fin}.
Le mot anglais {\idt then} se prononce très approximativement `zen' (avec un cheveu sur la langue).

Quand il n'y a qu'une seule instruction à exécuter, on peut omettre le {\mcl begin} et
le {\mcl end}, comme dans `{\mcl if}\ {\idt tw\ ()}\ {\mcl then}\ {\idt pqtd\ ()}'.
\underline{Une erreur grave} est d'oublier le {\mcl begin} et le {\mcl end} quand il y a 
plusieurs instructions. Par exemple dans~:
{
\parindent \parindentprog
\medskip

\vspace{\neglskip}\mbox{\blc {\mcl if}{\idt \ tw\ ()\ }{\mcl then}{\idt \ pqtd\ ();\ av\ ()}}\par

\medskip }
\noindent seule l'instruction {\idt pqtd ()} dépend du test~: l'instruction {\idt av ()}
qui suit le point-virgule est toujours exé\-cu\-tée, que le \robot\ soit tourné vers l'ouest ou non.
Le compilateur ne peut pas signaler cette erreur puisque le programme est correct (mais ne fait pas
ce que l'on voulait). Notons aussi que l'instruction de test ``if'' est {\em une} instruction~:
si d'autres instructions la suivent, elle doit en être séparée par un point-virgule.

\section*{Addenda}
\index{Test}
L'instruction de test {\idt si} \ldots {\idt alors} \ldots {\idt sinon} \ldots fut introduite vers la fin des années
1950 dans le langage de programmation {\sc algol 60}. Ce langage, conçu par un groupe
d'experts internationaux, eut une très grande influence dans la conception de langages de programmation
ultérieurs notamment {\sc algol w}, \pascal, {\sc ada},  {\sc modula} et bien d'autres.  
Une autre forme d'instruction de test par cas fut introduite dans le langage de programmation 
{\sc algol w} (également conçu par N. Wirth) et reprise en \pascal\ sous le nom de ``case''.
En \ocaml, l'instruction de test par cas s'appelle le {\em filtrage} (``match'' en anglais).
Elle généralise l'instruction ``if'' qui peut s'écrire comme suit~:

{
\parindent \parindentprog
\medskip

\vspace{\neglskip}\mbox{\blc {\mcl match}{\idt \ expressionBooleenne\ }{\mcl with}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ }{\mcl true}{\idt \ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ }{\mcl false}{\idt \ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}}\par

\medskip }

De manière plus générale, le filtrage permet de choisir quelle séquence d'instructions doit
être exécutée en fonction de la valeur d'une expression. Par exemple {\idt valOrientation ()} est
égal au numéro de l'orientation du \robot\ (0 pour le nord, 1 pour le nord-est, 2 pour l'est, 
etc.). On pourra écrire~:
 

\index{Test}
{
\parindent \parindentprog
\medskip

\vspace{\neglskip}\mbox{\blc {\mcl match}{\idt \ valOrientation\ ()\ }{\mcl with}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ 0\ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}{\idt \ \ }{\cmt (*\ nord\ *)}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ 1\ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}{\idt \ \ }{\cmt (*\ nord{-}est\ *)}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ 2\ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}{\idt \ \ }{\cmt (*\ est\ *)}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ 3\ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}{\idt \ \ }{\cmt (*\ sud{-}est\ *)}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ 4\ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}{\idt \ \ }{\cmt (*\ sud\ *)}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ 5\ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}{\idt \ \ }{\cmt (*\ sud{-}ouest\ *)}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ 6\ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}{\idt \ \ }{\cmt (*\ ouest\ *)}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ 7\ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}{\idt \ \ }{\cmt (*\ nord{-}ouest\ *)}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ \_\ {-}\char62{}\ ()\ \ \ \ \ \ \ \ \ \ \ \ \ }{\cmt (*\ impossible\ *)}}\par

\medskip }


\noindent Tous les cas possibles doivent être prévus. Le compilateur ne sait pas que l'orientation
est comprise entre 0 et 7. Si l'on oublie le dernier cas, il signale
`{\tt this pattern-matching is not exhaustive}' (ce filtrage n'est pas exhaustif).
Le dernier cas `{\idt \_}' (souligné) regroupe toutes les autres valeurs, comme le mot
{\mcl otherwise} (`autrement' en anglais) de certaines extensions de \pascal. 
L'instruction {\idt ()} ne fait rien. Plusieurs cas semblables peuvent être regroupés 
comme dans l'exemple ci-dessous~:

{
\parindent \parindentprog
\medskip

\vspace{\neglskip}\mbox{\blc {\mcl match}{\idt \ valOrientation\ ()\ }{\mcl with}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ 0\ \char124{}\ 2\ \char124{}\ 4\ \char124{}\ 6\ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}{\idt \ \ }{\cmt (*\ N,\ E,\ S,\ W\ *)}}\par
\vspace{\neglskip}\mbox{\blc {\idt \char124{}\ \_\ {-}\char62{}\ }{\mcl begin}{\idt \ ...\ }{\mcl end}{\idt \ \ \ \ \ \ \ \ \ \ \ \ \ \ }{\cmt (*\ autres\ cas\ *)}}\par

\medskip }

\vspace{\abovedisplayskip}
\end{minipage}
}
